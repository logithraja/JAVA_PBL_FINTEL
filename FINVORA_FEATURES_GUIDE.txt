====================================================
FINVORA - FINANCE TRACKER : COMPLETE PROJECT GUIDE
====================================================

Overview
--------
Finvora is a modern, responsive JavaFX desktop application with a Spring Boot backend designed for personal finance management. It allows you to track expenses, set budgets and savings goals, visualize data, and leverages advanced AI capabilities to make financial tracking seamless. 

Architecture & Connections
--------------------------
1. Frontend (Client): Built with JavaFX. Handles UI, interactions, local storage (for Budgets and Goals in JSON files), and communicates with the backend via REST API (`ApiClient`).
2. Backend (Server): Built with Spring Boot (Java 17). Exposes REST endpoints (`/api/v1/...`) for Users, Transactions, Categories, and AI Forecasts. Uses an H2 embedded database for persistence.
3. Security: JWT token-based authentication.
4. External APIs: Integrates with Google Gemini via HTTP requests for advanced AI features.

=========================
CORE FEATURES & USAGE
=========================

1. Authentication Flow
- Launch the application to see the Login screen. 
- You can toggle to the Sign Up screen to register a new account.
- Once registered, login using your email and password. A JWT token is generated by the backend and cached by the client.

2. Dashboard & Visualization
- The Dashboard shows your current Balance, Total Income, Total Expense, Budget Remaining, and Savings Goal progress.
- Top Menu Bar provides access to Budgets, Savings Goals, Categories, Reports, and System settings.
- The Year and Month dropdowns allow you to filter the transaction table. (Now updated to show a full range of years).
- Click the "View Chart" button to see visual representations of your income vs expenses for the selected year/month.

3. Transaction Management
- Add manually using the "+" button. Fill in the vendor, amount, date, and category.
- View Recent Transactions in the scrollable panel on the right. 
- Double click any row in the transaction table to see all transactions for that specific month.

4. Budgets and Savings Goals
- Navigate to Budgets > Set Monthly Budgets to assign a limit to specific categories. Your dashboard will instantly track this against your current spending.
- Navigate to Savings Goals > Add Goal to set a target. The progress bar on the dashboard tracks your top goal.

5. Data Export & PDF Reports
- Navigate to Export / Reports to download your transaction history as a CSV file.
- Generate a comprehensive PDF report that summarizes your balances, budgets, and itemizes all transactions in a chosen date range.

6. Currency Converter
- Use the Currency Convert menu to check exchange rates on the fly.

=========================
AI CAPABILITIES & USAGE
=========================

Finvora heavily integrates AI to automate tracking and provide intelligent insights.

1. AI Vision Receipt Scanner
   - What it does: Extracts Vendor Name, Total Amount, Date, and Category directly from an image or PDF of a receipt using Google Gemini Pro Vision.
   - How to use: Click the "📷 Scan" button on the dashboard. Select an image or PDF of your receipt.
   - Duplicate Protection: Once the data is extracted, the app will automatically check against your existing database to see if a similar transaction already exists (matching merchant, amount, and date). If it detects a duplicate, it prompts you to confirm before saving. 

2. Proactive AI Alerts
   - What it does: Runs asynchronously in the background every time you load your dashboard. It feeds your recent transactions and budget limits to Gemini AI to look for anomalies, unusual spending patterns, or budget warnings.
   - How to use: Check the "🔔 AI Alerts" button in the top right of the navigation bar. If the text is red and says (1) or more, click it to read the insights Finvora generated about your spending habits.

3. Finvora AI Assistant
   - What it does: An interactive chat interface powered by Gemini. You can ask for financial advice OR give it commands.
   - How to use: Click the "✨ Finvora AI" button on the top navigation bar. 
   - Intent execution: You can type things like "Add an expense for Starbucks for 5.50 today" or "Take me to my budgets". The AI parses your intent into JSON and the client application automatically executes the action on your behalf.

4. Monthly Spending Forecast
   - What it does: A banner on the dashboard that dynamically calculates your pacing for the current month.
   - How to use: It is automatically visible on the dashboard. It calculates your daily average spend for the selected month, projects it to the end of the month, and compares it to your active budget limit to let you know if you're on track to overspend or come in under budget.

=========================
HOW TO RUN THE APPLICATION
=========================
You can run the entire suite using the provided scripts in the project root:
- Windows: Open PowerShell and run `.\run-all.ps1` or run `run-all.bat`
- This will launch two separate terminal windows. One will start the Spring Boot backend using Maven, and the other will compile and launch the JavaFX client. 
- Ensure you have Maven and Java 17+ installed and correctly added to your system PATH.
