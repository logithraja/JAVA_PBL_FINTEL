1. PROJECT OVERVIEW & 100% PURE JAVA ARCHITECTURE
================================================================================
Finvora is a modern personal finance desktop application built strictly on Java.
It uses a decoupled client-server architecture:

1. Backend Server:
   - Framework: Spring Boot 3 (Java 17+)
   - Security: Spring Security 6 with stateless HMAC-SHA256 JWT Authentication
   - Persistence: Embedded H2 Database (persisted to ./data/expense_tracker_db)
   - Docs: OpenAPI 3 / Swagger UI at http://localhost:8080/swagger-ui.html

2. Frontend Desktop App:
   - Framework: JavaFX 23
   - Styling: Modern CSS with light/dark theme support
   - Reporting: Apache PDFBox for PDF generation & CSV export
   - AI Engine: Multi-LLM fallback chain (Gemini 2.5 Flash, OpenAI GPT-4o-mini, Mistral)

2. HOW TO RUN FINVORA (BEGINNER STEP-BY-STEP)
================================================================================

METHOD 1: THE 1-CLICK METHOD (EASIEST)
---------------------------------------
1. Open Windows File Explorer and navigate to:
   D:\3sem\JAVA PROJECT\finvora-desktop-main\
2. Double-click "run-all.bat".

What happens:
- Two terminal windows will open.
- Window 1 starts the Spring Boot Backend Server (port 8080).
- Window 2 automatically starts the JavaFX Desktop App.
- The Finvora Login window will appear on your screen.

METHOD 2: USING POWERSHELL / TERMINAL
---------------------------------------
1. Open PowerShell and navigate to the project directory:
   cd "d:\3sem\JAVA PROJECT\finvora-desktop-main"

2. Run the all-in-one launcher script:
   .\run-all.ps1

(Or run each individually):
   .\run-server.ps1   # Starts Spring Boot Backend
   .\run-client.ps1   # Starts JavaFX Client

3. FULL SYSTEM ARCHITECTURE & COMPONENT DECODING
================================================================================

[ JavaFX Desktop Client ]
       |
       |-- (HTTP + Bearer JWT) --> [ Spring Security Filter Chain ]
       |                                      |
       |                                      v
       |                          [ Spring Boot Controllers ]
       |                          - UserController
       |                          - TransactionController
       |                          - TransactionCategoryController
       |                          - SavingsGoalController
       |                                      |
       |                                      v
       |                          [ Persistent H2 Database ]
       |
       |-- (Direct HTTPS REST) --> [ Multi-LLM AI Engine ]
                                  - Google Gemini 2.5 Flash
                                  - OpenAI GPT-4o-mini / Whisper
                                  - Mistral Large / Pixtral

DATA ISOLATION & SECURITY:
- BCrypt password hashing is enforced on user registration.
- All subsequent REST calls require the JWT token in Authorization: Bearer <token>.
- Every database query verifies user ownership (verifyUserOwnership(userId, principal)).

4. ZERO-PYTHON ARCHITECTURE (100% PURE JAVA)
================================================================================
All previous Python scripts (such as stt.py) have been completely removed.
There are ZERO Python files and ZERO Python dependencies in this repository.

Audio transcription (Speech-to-Text) is implemented natively in Java:
- Located in: org.example.services.AIEngine and org.example.services.AIVoiceService
- Method: AIEngine.transcribeAudio(byte[] audioBytes, String mimeType)
- Communicates directly via Java's native java.net.http.HttpClient with Gemini/Whisper audio APIs.
- Text-to-Speech (TTS) streams infinite audio chunks directly in JavaFX MediaPlayer.

6. FEATURE BREAKDOWN & HOW TO USE
================================================================================
- Add Transactions: Click "+ Add Transaction" (Income/Expense with Category, Time, Date).
- Set Monthly Budgets: Menu -> Budgets -> Set Monthly Budgets (Tracks spending limits).
- Savings Goals: Menu -> Goals -> Add Savings Goal (Tracks progress towards target).
- AI Receipt Scanner: Click "Scan Receipt" to upload receipt images (.jpg/.png).
- View Charts: Click "View Chart" to view monthly breakdowns and bar graphs.
- Export Data: Menu -> Export -> Export to CSV or Generate PDF Report.
- AI Assistant: Click "Finvora AI" to open conversational AI with live context.
- Currency Converter: Menu -> Tools -> Currency Converter.
